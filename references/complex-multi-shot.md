# 复杂视频反推：多镜头 / 切镜 / 转场 / 对白 / 长片

低动态单镜头片用主流程即可。遇到多镜头、硬切、转场、人物对白或长片，先按下文分级，再决定"整条复刻"还是"分镜逐条生成"。文生视频单条只能复现连续单镜头，**不要承诺用一条提示词复刻多镜剧情片**。

## 1. 复刻可行性分级（写进交付说明，不藏）
- **高**：静物、单一物体运动、氛围/风景、简单 Loop——单条提示词可整条复刻。
- **中**：单人单一动作、产品展示、固定场景小变化——可单条，动作表情写具体。
- **低**：多镜头叙事、多人互动、特定人脸、复杂调度、精确对白口型、长剧情——单条无法复刻，改用"分镜逐条生成 + 用户后期剪辑"，并明确说明这一界限。

## 2. 先找切点（用脚本辅助，不靠肉眼估）
1. 先 `extract_frames.py --count N` 均匀抽全片，肉眼标出疑似切点。
2. 再跑 `scripts/detect_cuts.py <video.mp4>`，用帧差/场景分阈输出硬切时间点，与肉眼标注互证；切点前后用 `fps≥2` 密抽复核。
3. 每个镜头独立记录，字段齐全：
   - 镜号 SH001…；起止时间；景别；机位角度/焦段景深；主体与朝向、表情；该镜主动作逐拍；运镜轨迹；光色；声音/台词；本镜新增信息。
   - 切点时间、切法（硬切/动作中切/视线切/反应切/遮挡切/叠化/甩镜/匹配）。
   - 承接：上一镜如何接到下一镜（动作、视线、声音桥、形状、状态对比），切后新增什么。
4. 复刻方式：为**每个镜头各写一条双版本提示词**（通用中英+五段式），逐条文生；镜头间剪辑、切点、转场由用户在剪辑软件完成，本技能不负责拼接。

## 3. 跨镜连续性（全方位复刻关键，最容易丢）
- **人物身份一致**：同一角色跨镜复用同一套外观绑定（发型/服装/配饰），在底稿开头统一写一次，每镜引用，不每镜换描述。
- **方向一致**：人物朝左还是朝右、视线方向、运动方向跨镜保持；正反打时两人左右位置固定（A 在左、B 在右），不要镜像跳反。
- **光色统一**：全片风格色板、冷暖倾向、颗粒在底稿开头锁定，每镜沿用；单镜内光向写死。
- **运动接续**：上一镜走出画面的方向 = 下一镜进入画面的方向；转身、抬手等动作在切点处连续。
- **声音桥**：上一镜尾音/BGM 节拍延到下一镜开头，标注在承接列。

## 4. 转场反推与可复现性
- 可文生复现：叠化/淡入淡出、缓慢推进中的自然过渡、动作连续。
- 需后期/标注"不可单条复现"：匹配剪辑、遮挡转场、画面翻转、缩放甩镜、特殊遮罩转场、复杂 MG 变形。
- 反推只如实记录转场发生在第几秒、由什么触发；复刻提示词写"简单过渡"，复杂转场在交付清单标"需后期"。

## 5. 对白与人物
- 台词逐字转写，用 `人物对白（角色）：{逐字原文}`；情绪、语速、口型写在括号外。
- 外观锁定：发型、年龄感、服装、配饰、朝向；文生无法逐字对嘴，交付注明"口型为近似，精确对白建议后期配音/对口型"。
- 多人场只反推可见项，不补写未出现的关系与背景。

## 6. 长片拆段（超出单条生成上限时）
- 按模型单条上限（2.0 fast/2.0 为 4–15s；2.5 为 4–30s）切连续段 SEG01、SEG02…，不是独立短视频。
- 全片共享同一人物身份、场景、光色、风格、主线；后段延续前段已发生状态，不重新开场。
- 非首段需以上一段真实尾帧承接；无法提供承接时降级为时间省略/跳切并注明。
- 每段单独写双版本提示词，逐条生成，最后由用户剪辑拼接。

## 7. 复杂片交付清单
- 可行性分级结论；全片风格色板与人物身份绑定；分镜表（镜号/时间/景别机位/朝向表情/动作/运镜/光色/台词声音/切镜承接）；每镜双版本提示词；需后期项（剪辑、对口型、字幕、转场、真实人脸/招牌）；文生局限说明。
