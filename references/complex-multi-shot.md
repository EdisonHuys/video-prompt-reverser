# 复杂视频反推：多镜头 / 切镜 / 转场 / 对白 / 长片

低动态单镜头片用主流程即可。遇到多镜头、硬切、转场、人物对白或长片，先按下文分级，再决定"整条复刻"还是"分镜逐条生成"。文生视频单条只能复现连续单镜头，**不要承诺用一条提示词复刻多镜剧情片**。

## 1. 先做复刻可行性分级（写进交付说明，不藏）
- **高**：静物、单一物体运动、氛围/风景、简单 Loop——单条提示词可整条复刻。
- **中**：单人单一动作、产品展示、固定场景小变化——可单条，动作需写具体。
- **低**：多镜头叙事、多人互动、特定人脸、复杂调度、精确对白口型、长剧情——单条无法复刻，改用"分镜逐条生成 + 用户后期剪辑"，并在交付时明确说明这一界限。

## 2. 多镜头/切镜反推（按镜头拆，不按秒糊成一段）
抽帧后先找切点（景别、主体位置、视角突变处），每个镜头独立记录：
- 镜号 SH001…；时间段；景别；机位角度；主体与朝向；该镜主动作；光色；声音/台词；本镜新增信息。
- 切点理由与承接：硬切 / 动作中切 / 视线切 / 遮挡切 / 形状匹配 / 声音桥；上一镜如何接到下一镜。
- 复刻方式：为**每个镜头/节拍各写一条提示词**（通用版+五段式），逐条文生；镜头之间的剪辑关系、切点由用户在剪辑软件完成，本 Skill 不负责拼接。

## 3. 转场反推与可复现性
逐段标注转场类型，并标明文生能否复现：
- 可文生复现：叠化/淡入淡出、缓慢推进中的自然过渡、动作连续。
- 需后期/标注"不可单条复现"：匹配剪辑、遮挡转场、画面翻转、缩放甩镜、特殊遮罩转场、复杂 MG 变形。
- 反推只如实记录转场发生在第几秒、由什么触发；复刻提示词里写明"简单过渡"，复杂转场在交付清单标"需后期"。

## 4. 对白与人物
- 台词逐字转写，用 `人物对白（角色）：{逐字原文}`；口型、情绪、语速写在括号外。
- 外观锁定：发型、年龄感、服装、配饰、朝向；文生无法逐字对嘴，交付注明"口型为近似，精确对白建议后期配音/对口型"。
- 多人场只反推可见项，不补写未出现的关系与背景。

## 5. 长片拆段（超出单条生成上限时）
- 按模型单条上限（2.0 fast/2.0 为 4–15s；2.5 为 4–30s）切连续段 SEG01、SEG02…，不是独立短视频。
- 全片共享同一主体身份、场景、光色、主线；后段延续前段已发生状态，不重新开场。
- 非首段需以上一段真实尾帧承接；无法提供承接时降级为时间省略/跳切并注明。
- 每段单独写双版本提示词，逐条生成，最后由用户剪辑拼接。

## 6. 复杂片交付清单
- 可行性分级结论；分镜表（镜号/时间/景别/动作/声音/承接）；每镜双版本提示词；需后期项；文生局限说明。
