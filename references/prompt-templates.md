# 全方位复刻双版本提示词模板与迭代规则

反推完成后，**同时产出两套**：通用可移植版（中文+英文，给即梦/可灵/剪映/Runway/Pika）和豆包五段式版。两套描述同一对象，要素必须一致。术语从 `cinematic-vocabulary.md` 取，不堆砌空词。

## 一、通用可移植版（中文模板）

> {画幅比例}，{总时长}秒，{类型质感，如夜晚手持纪实/MV卡点/电影感}，{有无人物/文字/对白}。【画面风格】{色板、冷暖、饱和度、对比、颗粒、稳定度}；【光线】{主光方向、光源、色温、软硬、光斑}；【主体】{外观：发型/服装/配饰/朝向} + {表情：眉眼嘴/情绪}；【动作逐拍】{时间→动作形态、方向、起止，手部与头发二级反馈}；【机位】{景别+角度+焦段景深+主体位置/视线方向}；【运镜】{固定/推/拉/摇/移/跟/环绕，起幅→落幅，速度方向，手持晃幅}；【切镜】{本镜是否单镜；切点/转场由后期，写明承接锚点}；{背景元素}，{主色调}，{光质}，{情绪}，{质感}。

### 通用英文版模板（跨工具）

> {Aspect ratio}, {duration}s {genre/look}, no people/no text/no dialogue. {Grade: palette, warm/cool, saturation, contrast, grain, stability}; {Light: direction, source, color temp, soft/hard, bokeh}; {Subject: hair/outfit/accessories/orientation} with {expression: brows/eyes/mood}; {action beat by beat: shape, direction, start→end, hand/hair feedback}; {shot size + angle + lens/DOF + subject position/gaze}; {camera move: static/push/pull/pan/track/follow/orbit, start→end, speed, handheld shake}; {cut: single shot; transitions in post, anchor}; {background}, {palette}, {light quality}, {mood}, {texture}.

填写要点：一条连贯长句，顺序为"画幅时长 → 风格调色 → 光 → 主体外观+表情 → 动作逐拍 → 机位 → 运镜 → 切镜 → 背景色调氛围"。把观察清单 J 节易漏项全部写死（朝向、光向、运镜、动作方向、表情、切点、画幅时长、有无台词文字）。

## 二、豆包五段式模板（纯文生，本平台复刻最稳）

**第1段 输入资产定位与0秒基准**：声明纯文生/无参考图（图生则写明参考图职责）；写清第0秒画面基准：景别、主体位置/朝向/表情、光、背景状态、主动作起始、运镜起点。

**第2段 参考主体绑定与生成目标**：逐项锁定外观（发型/服装/配饰/朝向）与表情基调；一句话写生成目标（复现什么画面/氛围/镜头）；列禁止出现的大类（多余人物、文字、错侧光、错误运镜、冷/暖色偏差）。

**第3段 逐时间段动作、表情、声音与脚本**：按 0–1s / 1–3s / 3–末秒 切分；每段写主体动作+表情变化+手部/头发反馈、镜头运动（推/跟/固定及速度）、声音（无人声也写明"氛围环境声，无人声"）。台词用 `人物对白（角色）：{逐字原文}`，标注情绪语速；MV 歌词逐字。

**第4段 转场与尾态收束**：写明本镜是否单镜头、有无切镜转场（复杂切镜标注"后期剪辑完成"）；尾帧停在何景别/表情/动作，是否出现文字/CTA/名单。

**第5段 全片一致性与禁区**：重申贯穿全片的风格色板、朝向、光向、运镜、表情基调；用"禁止……"列易跑偏项（错侧光、直推变环绕、表情错、多余人物、文字水印、冷暖偏差、手持幅度过大）。

## 四、复刻对比与迭代规则

1. 用提示词纯文生生成复刻片，抽帧后与原片按观察清单逐项核对，做成对照表（命中项/可接受差异/未命中项）。
2. 命中即保留；未命中只改对应描述，不整段重写：
   - 主体/朝向错 → 第2段绑定与通用版主体句补朝向、颜色、服装。
   - 表情错 → 第3段把眉眼嘴情绪写具体，第5段禁区加错误表情。
   - 动作形态/方向错 → 第3段写清方向起止与手部头发反馈。
   - 光向错 → 通用版与五段式第1/5段同时改光向。
   - 运镜错（推近变环绕/固定变跟）→ 第3段写明"仅缓慢推近，禁止环绕/横移"。
   - 机位/景别错 → 第1段基准与通用版机位句补景别角度焦段。
3. 每轮只集中修订一次，重新生成对比；核心要素（主体、表情、主动作、光向、机位、运镜、画幅时长、风格氛围）全部命中即达标。
4. 文生无法逐像素一致：人物长相、服装纹样、随机粒子、镜面反射细节属正常边界，不反复重生；只在核心要素缺失时迭代。
5. 复刻片与原片都保存链接，输出对照结论（命中项/可接受差异/未命中项）。
