# 双版本提示词模板与迭代规则

反推完成后，**同时产出两套**：通用可移植版（给即梦/可灵/Runway/Pika 等）和豆包五段式版。两套描述同一对象，要素必须一致。

## 一、通用可移植版（中文模板）

> {画幅比例}，{总时长} 秒，{类型/氛围}，{有无人物/文字/对白}。{主光方向、光源、光效}；{主体：材质颜色形状朝向 + 关键细节}；{承载/位置}；{主动作：形态、方向、起止}。{机位角度}，{运镜：起幅→落幅、速度}；{景深}，{背景元素}，{主色调}，{光质}，{情绪}，{质感}。

### 通用英文版模板（跨工具）

> {Aspect ratio}, {duration}s {genre/mood} shot, no people/no text/no dialogue. {Light direction, source, beam}; {Subject: material, color, shape, orientation, key detail} on {supporting surface}; {main action: shape, direction, start→end}. {Camera angle}, {camera move: start→end, speed}; {DOF}, {background}, {palette}, {light quality}, {mood}, {texture}.

填写要点：一条连贯长句，顺序为"画幅时长 → 光 → 主体 → 动作 → 机位运镜 → 背景色调氛围"；把观察清单 G 节的易漏项全部写死，不写"高级感""氛围感"这类空词。

## 二、豆包五段式模板（纯文生，本平台复刻最稳）

**第1段 输入资产定位与 0 秒基准**：声明纯文生/无参考图；写清第0秒的画面基准（主体位置、朝向、光、背景状态、主动作起始）。

**第2段 参考主体绑定与生成目标**：逐项锁定主体材质、颜色、朝向、关键细节；用一句话写出生成目标（复现什么画面/氛围），并列明禁止出现的大类。

**第3段 逐时间段动作、声音与脚本**：按 0–1s / 1–3s / 3–末秒 切分；每段写主体动作、镜头推进、声音（无人声也要写明"氛围环境音，无人声"）。台词用 `形式：{逐字原文}`，本反推场景原片无台词就写无人声。

**第4段 转场与尾态收束**：写明是否单镜头、有无切镜转场特效；尾帧停在何处，是否出现文字/CTA。

**第5段 全片一致性与禁区**：重申贯穿全片的颜色、朝向、光向、色调；用"禁止……"列反推易跑偏项（人物、文字、错侧光、直烟、冷色、环绕运镜等）。

## 三、复刻对比与迭代规则（闭环）

1. 用提示词纯文生生成复刻片，抽帧后与原片按观察清单逐项核对，做成对照表。
2. 命中即保留；未命中项只改对应描述，不要整段重写：
   - 主体/朝向错 → 第2段绑定与通用版主体句补写朝向、颜色、材质。
   - 动作形态错（如单缕螺旋变成直烟/多缕）→ 第3段把形态写具体，第5段禁区加"禁止直烟/多缕"。
   - 光向错 → 通用版与五段式第1/5段同时改光向。
   - 运镜错（推近变环绕）→ 第3段写明"仅缓慢推近，禁止环绕/横移"。
3. 每轮只集中修订一次，重新生成对比；核心要素（主体、主动作、光向、运镜、画幅时长、氛围）全部命中即达标。
4. 文生视频无法逐像素一致：杯型饱满度、纹路细节、随机漂浮粒子属正常边界，不反复重生；只在核心要素缺失时迭代。
5. 复刻片与原片都保存链接，输出对照结论（命中项 / 可接受差异 / 未命中项）。
