# 全方位复刻观察清单

配合 `scripts/extract_frames.py` 先抽帧（默认每秒1帧；多镜/长片用 `--count N` 均匀抽，切点附近再 `fps≥2` 密抽），再逐帧、逐镜头用本清单观察。**只写画面/音轨真实可见可闻的内容，不脑补、不套用原作者意图。** 每个镜头独立填一份，跨镜共用的人物外观与画面风格在底稿开头统一锁定。

术语拿不准时查 `cinematic-vocabulary.md`，选最贴近的标准词，不要自造模糊说法。

## A. 机器可复用信息（先取，直接进提示词）
- 时长、帧率、画幅、比例（9:16 / 16:9 / 1:1 …）、分辨率、是否上下黑边/裁切安全框。
- 是否有人物、是否有画面文字/logo/招牌原文、是否有人声对白。
- 音轨：台词逐字转写（说话人+原文）、BGM 风格/曲风/节拍、环境声、拟音；无人声时明确写"无人声对白"。

## B. 画面风格与调色（全片统一，单独成段写进提示词）
- 整体类型质感：胶片 / 数码纪实 / 电影感 / MV 卡点 / 手机随手拍 / 广告精致感 / 动画。
- 色板：主色、辅色、点缀色；偏暖还是偏冷；高饱和还是低饱和；对比强还是柔和。
- 色温倾向（暖橙/冷青/中性/青绿）、明暗反差（光比）、暗部死黑还是带灰、高光是否溢出。
- 颗粒/噪点轻重、锐度、柔焦/朦胧、是否有滤镜（青橙、复古、霓虹、黑白）。
- 画面稳定度：固定 / 手持轻晃 / 剧烈晃动 / 稳定器平滑。

## C. 机位与构图（逐镜）
- 景别：大远景/远景/全景/中景/中近景/近景/特写/大特写；起幅、落幅景别。
- 机位角度：平视 / 仰视 / 俯视 / 侧面 / 过肩 / 主观视角；镜头高度。
- 焦段与景深：广角深景 / 标准 / 长焦浅景深虚化；背景虚化程度。
- 主体在画面的位置（居中/左/右/上/下）、身体朝向（左/右/背/正面）、视线看向画面哪一侧。
- 构图：对称 / 三分 / 框中框 / 留白方向；前景遮挡物是什么。

## D. 运镜（逐镜，写清轨迹，不要只写"运镜"）
- 类型：固定 / 缓慢推近 / 拉远 / 摇（左右/上下）/ 横移 / 跟随 / 背后跟随 / 环绕 / 升降 / 甩镜 / 变焦。
- 起幅→落幅的景别与位置变化；速度（极慢/中速/快速）与方向；手持晃幅大小。
- 运镜与主体动作如何配合（跟人走、随动作推、停在表情上）。

## E. 切镜与转场（多镜头必填）
- 切点精确时间（秒）；切点前后景别/视角/主体变化。
- 切法：硬切 / 动作中切 / 视线切 / 反应切 / 遮挡切 / 叠化 / 淡入淡出 / 甩镜转场 / 匹配剪辑。
- 承接锚点：上一镜用什么动作、视线、声音、形状或状态接到下一镜；切后新增了什么信息。

## F. 主体、表情与动作（逐拍拆时间轴）
- 外观绑定（跨镜一致）：性别感、年龄段、发型发色、服装款式颜色、配饰、鞋；只写可见项。
- 表情：眉（抬/皱/平）、眼（睁/垂/看向哪）、嘴（闭/微笑/张开发声）、整体情绪（平静/笑/惊讶/落寞…）。
- 动作逐拍：按 0–1s / 1–3s … 写出谁在什么时间做了什么，动作从哪到哪、如何承接；主动作 + 二级反馈（头发甩动、呼吸、布料、道具、视线转移）。
- 手部动作：扶耳机、插兜、抬手、触碰等具体位置与方向。

## G. 台词与声音（逐句锁定）
- 人物对白（角色）：{逐字原文}；标注情绪、语速、口型是否可见。
- BGM：曲风、男女声、快慢节拍、卡点位置；歌词逐字（若为 MV）。
- 环境声/拟音：车流、脚步、电梯叮、衣料声等；无人声也要写明氛围环境声。

## H. 光线色彩（逐镜）
- 主光方向（左/右/顶/逆光/侧逆）、光源（路灯/招牌/顶灯/窗光/霓虹）、色温、软硬、光比、是否有光斑/丁达尔/反光。

## I. 节奏与尾态
- 快慢曲线、单镜头还是多镜、每个切点理由；尾帧停在哪里、有无标题卡/字幕/CTA/片尾名单。

## J. 易漏项自查（逐条勾）
- [ ] 主体朝向/左右（脸、手、道具朝哪侧，不要写反）
- [ ] 光从哪边来（不要写成另一侧）
- [ ] 运镜类型、方向、速度、起幅落幅（推近≠固定，环绕≠跟随）
- [ ] 主动作形态与方向（往哪走、手往哪抬、头发往哪甩）
- [ ] 表情具体到眉眼嘴，不只写"有情绪"
- [ ] 切点精确时间、切法、承接锚点
- [ ] 台词逐字 + 说话人 + 情绪语速，不默认加旁白
- [ ] 画幅、时长、帧率感；是否真的无人声/无文字
- [ ] 画面风格/色板/颗粒全片统一，写进每镜或单列风格段
