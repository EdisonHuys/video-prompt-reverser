# 逐帧反推观察清单

配合 `scripts/extract_frames.py` 先抽帧（默认每秒1帧；长片用 `--count N` 均匀抽），再逐帧用本清单观察。**只写画面/音轨真实可见可闻的内容，不脑补、不套用原作者意图。**

## A. 机器可复用信息（先取，直接进提示词）
- 时长、帧率、画幅、比例（9:16 / 16:9 / 1:1 …）
- 是否有人物、是否有画面文字/logo、是否有人声对白
- 音轨：有无台词（转写原文）、BGM、环境声、拟音；无人声时明确写"无人声对白"

## B. 镜头与机位（逐帧对比景别变化）
- 景别：远景/全景/中景/中近景/近景/特写；起幅、落幅各是什么
- 机位角度：平视/俯视/仰视/侧逆光位；主体在画面中的位置、朝向（如"杯把朝右"）
- 运镜：固定 / 缓慢推近 / 拉远 / 横移 / 跟随 / 环绕 / 升降；速度与方向；是否有切镜与转场
- 焦段与景深：长焦浅景深虚化 / 广角深景

## C. 主体外观（绑定一致性，逐项锁定）
- 人：性别感、年龄段、发型、服装、肤色、配饰、所处状态（只写可见项）
- 物：材质、颜色、形状、大小比例、朝向、标志性细节（拉花纹路、包装、logo 位置）
- 环境：空间类型、关键道具、背景元素、墙面/地面材质

## D. 动作与运动链（按时间拆成连续节点）
- 主体在每个时间段做了什么，动作从哪到哪、如何承接
- 唯一主动作与二级反馈；被动元素如何动（热气、头发、水面、布料）
- 与镜头运动如何配合；结尾停在什么状态

## E. 光线与色彩
- 主光方向（左/右/顶/逆光）、色温（暖橙/冷蓝/中性）、软硬、光比、是否有光柱/丁达尔/光斑
- 主色调、饱和度、氛围情绪

## F. 节奏与尾态
- 快慢曲线、单镜头还是多镜、切点理由；尾帧停在哪里、有无 CTA/标题卡/文字

## G. 易漏项自查（反推最常丢，逐条勾）
- [ ] 主体朝向/左右（杯把、脸、道具朝哪侧）
- [ ] 光从哪边来（不要写成另一侧）
- [ ] 运镜类型与速度（推近≠固定，环绕≠跟随）
- [ ] 主动作的形态（单缕螺旋 vs 直烟、水泼向哪个方向）
- [ ] 关键细节（拉花、产品包装、字幕、口型）
- [ ] 画幅与时长（复刻时必须一致）
- [ ] 是否真的无人声/无文字，不要默认加旁白
